# Roadmap

## Delivered in v0.1

- Versioned fixed-workflow JSON contract and strict validation.
- Three real Docker permission configurations; four deterministic probes.
- Repeated isolated trials, immutable local image selection and artifact verification.
- Conservative verdicts and permission-set candidate selection.
- Portable checksum-bearing evidence, local report verification and baseline comparison.
- Static responsive dashboard, local import/export, evidence inspection and printable review.
- Unit tests, Docker integration CI and tag-driven release packaging.

## Next: stronger experimental scope

- Additional independently audited workflows with explicit positive and negative controls.
- More complete host/daemon fingerprint and signed CI evidence.
- Declarative constrained profile candidates, with compatibility validation.
- Per-boundary regressions alongside candidate loss.
- Systematic mount, identity and dependency variants with coverage accounting.

## Later: real-agent and microVM adapters

- Docker Sandboxes adapter against documented interfaces, feature-gated with capability checks.
- External verifier isolated from agent-controlled processes and artifacts.
- Repeated agent trials with explicit budget, model identity and task-quality validation.
- Permit-set frontier across distinct workflows, preserving incomparable candidates.

These are future capabilities. No current screen or README result should imply they already exist.
