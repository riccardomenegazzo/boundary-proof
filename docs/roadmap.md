# Capability status

Implemented: committed-repository evaluation, configurable profiles and commands, independent acceptance container, named-volume lifecycle, artifact hashes, optional tool-calling model adapter, authenticated local dashboard, contract editing, cancellation, persistent reports, comparison and packaged frontend assets.

Not implemented: Docker Sandboxes-native backend, kernel exploit assessment, network-policy optimization, cryptographic execution attestation, multi-user hosted runner, enterprise SSO and adversarially robust hardware verification. These are separate engineering scopes and are not advertised as current results.
