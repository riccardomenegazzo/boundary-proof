# Five-minute customer conversation

## 0:00 — Start with a decision

“Your platform team wants an AI workflow pilot. Security needs explicit boundaries. We will evaluate whether a small workflow finishes under each permission profile, and which declared conditions hold.”

State whether you are opening synthetic data or a measured Docker report. Do not present the bundled example as an observed customer outcome.

## 0:45 — Agree on the contract

Open Workflow contract. Identify the owner, task, required observations and repetitions. Explain that the fixture builds a package deterministically; it does not assess an LLM's coding quality.

## 1:30 — Compare the profiles

Open Permission frontier. Permissive access can enable useful work and violate conditions. A restrictive profile can block work. A candidate must preserve the task and satisfy the tested conditions in every repetition.

## 2:30 — Show the evidence

Select a run and expand its checks. For a real report, show task output and the controller's artifact verification. Explain why root identity differs from host escape, and why an execution error is inconclusive.

## 3:30 — Turn observations into a pilot plan

The platform owner reproduces the evaluation on an approved image and host. Security reviews the bounded conditions. The TAM records unresolved workflow needs and a review date. A candidate is a starting point for that conversation, not an automatic production approval.

## 4:30 — Preserve the decision

Export the report and establish a baseline. Compare a later evaluation with the same contract/environment. A changed environment requires a new baseline. A lost candidate prompts investigation; it is not automatically a customer security incident.

## Defensible claims

- “I built the runner, conservative evaluator and evidence dashboard.”
- “This release evaluates a deterministic fixture, not real autonomous agents.”
- “Its purpose is to make a customer adoption decision inspectable and repeatable.”
- “These bounded results do not certify a runtime against unknown attacks.”
